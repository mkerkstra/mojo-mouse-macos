# Security

Report vulnerabilities through GitHub’s private vulnerability reporting for this repository. If unavailable, open an issue with a non-sensitive summary and ask for a private reporting channel; do not publish credentials or a working exploit involving private data.

The app can configure a supported USB mouse. It does not read keystrokes, use a network service, install a login item, or flash firmware. Only the bundled HTML document can access the native message bridge. Imports are validated and do not enable automation or write to hardware on their own.

This initial public release is ad-hoc signed and not Apple notarized. Compare release checksums and review the source as appropriate. Never disable macOS security protections system-wide to run this app.

Only the latest release receives fixes. Hardware support and readback limitations are documented in the README.
