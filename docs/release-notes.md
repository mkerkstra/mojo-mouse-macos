## Mojo Mouse 0.2.0

- Native app information window with version, compatibility, privacy, and support details.
- Standard macOS Settings, Edit, and Help menu commands.
- A new original mouse icon with correct pixel sizes.
- App category metadata and a bundled privacy manifest.
- A separate sandboxed Xcode target for the Pointer Profiles Mac App Store edition, with experimental controls disabled.

The direct download continues to support Intel and Apple Silicon on macOS 13 or later. Supports only the wired MOJO MJ-189, USB 260d:1027. This download is ad-hoc signed and not Apple notarized. Checksums are supplied with the DMG and ZIP. App Store submission and approval are separate from this GitHub release.
